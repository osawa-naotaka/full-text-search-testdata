# Alphabet

Set of letters used to write a given language

This article is about alphabets in general. For the English alphabet in particular, see [English alphabet](https://en.wikipedia.org/wiki/English_alphabet "English alphabet"). For the international technology conglomerate, see [Alphabet Inc.](https://en.wikipedia.org/wiki/Alphabet_Inc. "Alphabet Inc.") For other uses, see [Alphabet (disambiguation)](https://en.wikipedia.org/wiki/Alphabet_\(disambiguation\) "Alphabet (disambiguation)").

An **alphabet** is a standard set of [letters](https://en.wikipedia.org/wiki/Letter_\(alphabet\) "Letter (alphabet)") written to represent particular sounds in a spoken language. Specifically, letters largely correspond to *[phonemes](https://en.wikipedia.org/wiki/Phoneme "Phoneme")* as the smallest sound segments that can distinguish one word from another in a given language.[\[1\]](https://en.wikipedia.org/wiki/#cite_note-1) Not all [writing systems](https://en.wikipedia.org/wiki/Writing_system "Writing system") represent language in this way: a [syllabary](https://en.wikipedia.org/wiki/Syllabary "Syllabary") assigns symbols to spoken [syllables](https://en.wikipedia.org/wiki/Syllable "Syllable"), while [logographies](https://en.wikipedia.org/wiki/Logographies "Logographies") assign symbols to [words](https://en.wikipedia.org/wiki/Word "Word"), [morphemes](https://en.wikipedia.org/wiki/Morpheme "Morpheme"), or other semantic units.[\[2\]](https://en.wikipedia.org/wiki/#cite_note-Daniels4-2)[\[3\]](https://en.wikipedia.org/wiki/#cite_note-3)

The first letters were invented in [Ancient Egypt](https://en.wikipedia.org/wiki/Ancient_Egypt "Ancient Egypt") to serve as an aid in writing [Egyptian hieroglyphs](https://en.wikipedia.org/wiki/Egyptian_hieroglyph "Egyptian hieroglyph"); these are referred to as [Egyptian uniliteral signs](https://en.wikipedia.org/wiki/Egyptian_uniliteral_sign "Egyptian uniliteral sign") by [lexicographers](https://en.wikipedia.org/wiki/Lexicographer "Lexicographer").[\[4\]](https://en.wikipedia.org/wiki/#cite_note-4) This system was used until the 5th century CE,[\[5\]](https://en.wikipedia.org/wiki/#cite_note-Houston-2003-5) and fundamentally differed by adding pronunciation hints to existing hieroglyphs that had previously carried no pronunciation information. Later on, these [phonemic](https://en.wikipedia.org/wiki/Phonemic "Phonemic") symbols also became used to transcribe foreign words.[\[6\]](https://en.wikipedia.org/wiki/#cite_note-Daniels-6) The first fully phonemic script was the [Proto-Sinaitic script](https://en.wikipedia.org/wiki/Proto-Sinaitic_script "Proto-Sinaitic script"), also descending from Egyptian hieroglyphs, which was later modified to create the [Phoenician alphabet](https://en.wikipedia.org/wiki/Phoenician_alphabet "Phoenician alphabet"). The Phoenician system is considered the first true alphabet and is the ultimate ancestor of many modern scripts, including [Arabic](https://en.wikipedia.org/wiki/Arabic_alphabet "Arabic alphabet"), [Cyrillic](https://en.wikipedia.org/wiki/Cyrillic_script "Cyrillic script"), [Greek](https://en.wikipedia.org/wiki/Greek_alphabet "Greek alphabet"), [Hebrew](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet"), [Latin](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet"), and possibly [Brahmic](https://en.wikipedia.org/wiki/Brahmic_scripts "Brahmic scripts").[\[7\]](https://en.wikipedia.org/wiki/#cite_note-Coulmas_140-7)[\[8\]](https://en.wikipedia.org/wiki/#cite_note-Daniels_9296-8)[\[9\]](https://en.wikipedia.org/wiki/#cite_note-Goldwasser-2012-9)[\[10\]](https://en.wikipedia.org/wiki/#cite_note-10)

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/2/24/Phoenician_alphabet.svg/220px-Phoenician_alphabet.svg.png)](https://en.wikipedia.org/wiki/File:Phoenician_alphabet.svg)

Corresponding letters in the Phoenician and Latin alphabets

[Peter T. Daniels](https://en.wikipedia.org/wiki/Peter_T._Daniels "Peter T. Daniels") distinguishes true alphabets—which use letters to represent both consonants and vowels—from both [abugidas](https://en.wikipedia.org/wiki/Abugida "Abugida") and [abjads](https://en.wikipedia.org/wiki/Abjad "Abjad"), which only need letters for consonants. Abjads generally lack vowel indicators altogether, while abugidas represent them with [diacritics](https://en.wikipedia.org/wiki/Diacritic "Diacritic") added to letters. In this narrower sense, the [Greek alphabet](https://en.wikipedia.org/wiki/Greek_alphabet "Greek alphabet") was the first true alphabet;[\[11\]](https://en.wikipedia.org/wiki/#cite_note-FOOTNOTECoulmas1999\[\[Category:Wikipedia_articles_needing_page_number_citations_from_November_2024]]%3Csup_class=%22noprint_Inline-Template_%22_style=%22white-space:nowrap;%22%3E\&#91;%3Ci%3E\[\[Wikipedia:Citing_sources|%3Cspan_title=%22This_citation_requires_a_reference_to_the_specific_page_or_range_of_pages_in_which_the_material_appears.\&#32;\(November_2024\)%22%3Epage\&nbsp;needed%3C/span%3E]]%3C/i%3E\&#93;%3C/sup%3E-11)[\[12\]](https://en.wikipedia.org/wiki/#cite_note-FOOTNOTEMillard1986396-12) it was originally derived from the [Phoenician alphabet](https://en.wikipedia.org/wiki/Phoenician_alphabet "Phoenician alphabet"), which was an abjad.[\[13\]](https://en.wikipedia.org/wiki/#cite_note-FOOTNOTEDanielsBright19963%E2%80%935,_91,_261%E2%80%93281-13)

Alphabets usually have a standard ordering for their letters. This makes alphabets a useful tool in [collation](https://en.wikipedia.org/wiki/Collation "Collation"), as words can be listed in a well-defined order—commonly known as [alphabetical order](https://en.wikipedia.org/wiki/Alphabetical_order "Alphabetical order"). This also means that letters may be used as a method of "numbering" ordered items. Some systems demonstrate [acrophony](https://en.wikipedia.org/wiki/Acrophony "Acrophony"), a phenomenon where letters have been given names distinct from their pronunciations. Systems with acrophony include Greek, [Arabic](https://en.wikipedia.org/wiki/Arabic_alphabet "Arabic alphabet"), [Hebrew](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet"), and [Syriac](https://en.wikipedia.org/wiki/Syriac_alphabet "Syriac alphabet"); systems without include the [Latin alphabet](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet").

More recently however, four cylinder seals dating to 2400 BC and found at the site of [Umm el-Marra](https://en.wikipedia.org/wiki/Umm_el-Marra "Umm el-Marra"), in present-day [Syria](https://en.wikipedia.org/wiki/Syria "Syria"), are incised with what is potentially the earliest known alphabetic writings in the world. The discovery suggests that the alphabet emerged 500 years earlier than previously thought, and undermines leading ideas about how it was invented.[\[14\]](https://en.wikipedia.org/wiki/#cite_note-14)[\[15\]](https://en.wikipedia.org/wiki/#cite_note-15)[\[16\]](https://en.wikipedia.org/wiki/#cite_note-16)[\[17\]](https://en.wikipedia.org/wiki/#cite_note-17) According to [Christopher Rollston](https://en.wikipedia.org/wiki/Christopher_Rollston "Christopher Rollston"), a scholar of the ancient Near East, the morphology of the letters on the cylinder seals parallels quite nicely that of the existing corpus of early alphabetic writing.[\[18\]](https://en.wikipedia.org/wiki/#cite_note-18) This theory however has yet to be universally accepted.

## Etymology

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=1 "Edit section: Etymology")]

The English word *alphabet* came into [Middle English](https://en.wikipedia.org/wiki/Middle_English "Middle English") from the [Late Latin](https://en.wikipedia.org/wiki/Late_Latin "Late Latin") word *alphabetum*, which in turn originated in the Greek ἀλφάβητος *alphábētos*; it was made from the first two letters of the Greek alphabet, *[alpha](https://en.wikipedia.org/wiki/Alpha_\(letter\) "Alpha (letter)")* (α) and *[beta](https://en.wikipedia.org/wiki/Beta_\(letter\) "Beta (letter)")* (β).[\[19\]](https://en.wikipedia.org/wiki/#cite_note-19) The names for the Greek letters, in turn, came from the first two letters of the Phoenician alphabet: *[aleph](https://en.wikipedia.org/wiki/Aleph "Aleph")*, the word for *ox*, and *[bet](https://en.wikipedia.org/wiki/Bet_\(letter\) "Bet (letter)")*, the word for *house*.[\[20\]](https://en.wikipedia.org/wiki/#cite_note-20)

### Alphabets related to Phoenician

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=3 "Edit section: Alphabets related to Phoenician")]

#### Ancient Near Eastern alphabets

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=4 "Edit section: Ancient Near Eastern alphabets")]

The [Ancient Egyptian writing system](https://en.wikipedia.org/wiki/Egyptian_hieroglyphs "Egyptian hieroglyphs") had a set of some [24 hieroglyphs](https://en.wikipedia.org/wiki/Egyptian_uniliteral_signs "Egyptian uniliteral signs") that are called uniliterals,[\[21\]](https://en.wikipedia.org/wiki/#cite_note-21) which are glyphs that provide one sound.[\[22\]](https://en.wikipedia.org/wiki/#cite_note-22) These glyphs were used as pronunciation guides for [logograms](https://en.wikipedia.org/wiki/Logogram "Logogram"), to write grammatical inflections, and, later, to transcribe loan words and foreign names.[\[6\]](https://en.wikipedia.org/wiki/#cite_note-Daniels-6) The script was used a fair amount in the 4th century CE.[\[23\]](https://en.wikipedia.org/wiki/#cite_note-23) However, after pagan temples were closed down, it was forgotten in the 5th century until the discovery of the [Rosetta Stone](https://en.wikipedia.org/wiki/Rosetta_Stone "Rosetta Stone").[\[5\]](https://en.wikipedia.org/wiki/#cite_note-Houston-2003-5) There was also [cuneiform](https://en.wikipedia.org/wiki/Cuneiform "Cuneiform"), primarily used to write several ancient languages, including [Sumerian](https://en.wikipedia.org/wiki/Sumerian_language "Sumerian language").[\[24\]](https://en.wikipedia.org/wiki/#cite_note-24) The last known use of cuneiform was in 75 CE, after which the script fell out of use.[\[25\]](https://en.wikipedia.org/wiki/#cite_note-25) In the [Middle Bronze Age](https://en.wikipedia.org/wiki/Middle_Bronze_Age "Middle Bronze Age"), an apparently alphabetic system known as the [Proto-Sinaitic script](https://en.wikipedia.org/wiki/Proto-Sinaitic_script "Proto-Sinaitic script") appeared in Egyptian turquoise mines in the [Sinai Peninsula](https://en.wikipedia.org/wiki/Sinai_Peninsula "Sinai Peninsula") c. 1840 BCE, apparently left by Canaanite workers. [Orly Goldwasser](https://en.wikipedia.org/wiki/Orly_Goldwasser "Orly Goldwasser") has connected the illiterate turquoise miner graffiti theory to the origin of the alphabet.[\[9\]](https://en.wikipedia.org/wiki/#cite_note-Goldwasser-2012-9) In 1999, American Egyptologists [John](https://en.wikipedia.org/wiki/John_Coleman_Darnell "John Coleman Darnell") and [Deborah Darnell](https://en.wikipedia.org/wiki/Deborah_Darnell "Deborah Darnell") discovered an earlier version of this first alphabet at the [Wadi el-Hol](https://en.wikipedia.org/wiki/Wadi_el-Hol "Wadi el-Hol") valley. The script dated to c. 1800 BCE and shows evidence of having been adapted from specific forms of Egyptian hieroglyphs that could be dated to c. 2000 BCE, strongly suggesting that the first alphabet had developed about that time.[\[26\]](https://en.wikipedia.org/wiki/#cite_note-26) The script was based on letter appearances and names, believed to be based on Egyptian hieroglyphs.[\[7\]](https://en.wikipedia.org/wiki/#cite_note-Coulmas_140-7) This script had no characters representing vowels. Originally, it probably was a syllabary—a script where syllables are represented with characters—with symbols that were not needed being removed. The best-attested Bronze Age alphabet is [Ugaritic](https://en.wikipedia.org/wiki/Ugaritic_alphabet "Ugaritic alphabet"), invented in [Ugarit](https://en.wikipedia.org/wiki/Ugarit "Ugarit") before the 15th century BCE. This was an alphabetic [cuneiform](https://en.wikipedia.org/wiki/Cuneiform "Cuneiform") script with 30 signs, including three that indicate the following vowel. This script was not used after the destruction of Ugarit in 1178 BCE.[\[27\]](https://en.wikipedia.org/wiki/#cite_note-27)

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/e/ec/Ba%60alat.png/220px-Ba%60alat.png)](https://en.wikipedia.org/wiki/File:Ba%60alat.png)

A specimen of the [Proto-Sinaitic script](https://en.wikipedia.org/wiki/Proto-Sinaitic_script "Proto-Sinaitic script"), one of the earliest phonemic scripts

The Proto-Sinaitic script eventually developed into the Phoenician alphabet, conventionally called [Proto-Canaanite](https://en.wikipedia.org/wiki/Proto-Canaanite_alphabet "Proto-Canaanite alphabet"), before c. 1050 BCE.[\[8\]](https://en.wikipedia.org/wiki/#cite_note-Daniels_9296-8) The oldest text in Phoenician script is an inscription on the sarcophagus of King [Ahiram](https://en.wikipedia.org/wiki/Ahiram "Ahiram") c. 1000 BCE. This script is the parent script of all western alphabets. By the 10th century BCE, two other forms distinguish themselves, [Canaanite](https://en.wikipedia.org/wiki/Canaanite_alphabet "Canaanite alphabet") and [Aramaic](https://en.wikipedia.org/wiki/Aramaic_alphabet "Aramaic alphabet"). The Aramaic gave rise to the [Hebrew alphabet](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet").[\[28\]](https://en.wikipedia.org/wiki/#cite_note-28)

The [South Arabian alphabet](https://en.wikipedia.org/wiki/South_Arabian_alphabet "South Arabian alphabet"), a sister script to the Phoenician alphabet, is the script from which the [Ge'ez abugida](https://en.wikipedia.org/wiki/Ge%27ez_abugida "Ge'ez abugida") was descended. Abugidas are writing systems with characters comprising consonant–vowel sequences. Alphabets without obligatory vowels are called *[abjads](https://en.wikipedia.org/wiki/Abjad "Abjad")*, with examples being Arabic, Hebrew, and [Syriac](https://en.wikipedia.org/wiki/Syriac_alphabet "Syriac alphabet"). The omission of vowels was not always a satisfactory solution due to the need of preserving sacred texts. "Weak" consonants are used to indicate vowels. These letters have a dual function since they can also be used as pure consonants.[\[29\]](https://en.wikipedia.org/wiki/#cite_note-29)[\[30\]](https://en.wikipedia.org/wiki/#cite_note-30)

The Proto-Sinaitic script and the Ugaritic script were the first scripts with a limited number of signs instead of using many different signs for words, in contrast to cuneiform, Egyptian hieroglyphs, and [Linear B](https://en.wikipedia.org/wiki/Linear_B "Linear B"). The Phoenician script was probably the first phonemic script,[\[7\]](https://en.wikipedia.org/wiki/#cite_note-Coulmas_140-7)[\[8\]](https://en.wikipedia.org/wiki/#cite_note-Daniels_9296-8) and it contained only about two dozen distinct letters, making it a script simple enough for traders to learn. Another advantage of the Phoenician alphabet was that it could write different languages since it recorded words phonemically.[\[31\]](https://en.wikipedia.org/wiki/#cite_note-FOOTNOTEHockJoseph200985-31)

The Phoenician script was spread across the Mediterranean by the Phoenicians.[\[8\]](https://en.wikipedia.org/wiki/#cite_note-Daniels_9296-8) The Greek alphabet was the first in which vowels had independent letterforms separate from those of consonants. The Greeks chose letters representing sounds that did not exist in Phoenician to represent vowels. The [Linear B](https://en.wikipedia.org/wiki/Linear_B "Linear B") syllabary, used by [Mycenaean Greeks](https://en.wikipedia.org/wiki/Mycenaean_Greeks "Mycenaean Greeks") from the 16th century BCE, had 87 symbols, including five vowels. In its early years, there were many variants of the Greek alphabet, causing many different alphabets to evolve from it.[\[32\]](https://en.wikipedia.org/wiki/#cite_note-32)

#### European alphabets

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=5 "Edit section: European alphabets")]

The Greek alphabet, in [Euboean form](https://en.wikipedia.org/wiki/Euboean_alphabet "Euboean alphabet"), was carried over by Greek colonists to the Italian peninsula c. 800–600 BCE giving rise to many different alphabets used to write the [Italic languages](https://en.wikipedia.org/wiki/Italic_languages "Italic languages"), like the [Etruscan alphabet](https://en.wikipedia.org/wiki/Etruscan_alphabet "Etruscan alphabet").[\[33\]](https://en.wikipedia.org/wiki/#cite_note-33) One of these became the Latin alphabet, which spread across Europe as the Romans expanded their republic. After the fall of the [Western Roman Empire](https://en.wikipedia.org/wiki/Western_Roman_Empire "Western Roman Empire"), the alphabet survived in intellectual and religious works. It came to be used for the [Romance languages](https://en.wikipedia.org/wiki/Romance_languages "Romance languages") that descended from Latin and most of the other languages of western and central Europe. Today, it is the most widely used script in the world.[\[34\]](https://en.wikipedia.org/wiki/#cite_note-34)

The Etruscan alphabet remained nearly unchanged for several hundred years. Only evolving once the [Etruscan language](https://en.wikipedia.org/wiki/Etruscan_language "Etruscan language") changed itself. The letters used for non-existent phonemes were dropped.[\[35\]](https://en.wikipedia.org/wiki/#cite_note-35) Afterwards, however, the alphabet went through many different changes. The final classical form of Etruscan contained 20 letters. Four of them are vowels—⟨a, e, i, u⟩—six fewer letters than the earlier forms. The script in its classical form was used until the 1st century CE. The Etruscan language itself was not used during the [Roman Empire](https://en.wikipedia.org/wiki/Roman_Empire "Roman Empire"), but the script was used for religious texts.[\[36\]](https://en.wikipedia.org/wiki/#cite_note-36)

Some adaptations of the Latin alphabet have [ligatures](https://en.wikipedia.org/wiki/Ligature_\(typography\) "Ligature (typography)"), a combination of two letters make one, such as [æ](https://en.wikipedia.org/wiki/%C3%86 "Æ") in [Danish](https://en.wikipedia.org/wiki/Danish_and_Norwegian_alphabet "Danish and Norwegian alphabet") and [Icelandic](https://en.wikipedia.org/wiki/Icelandic_alphabet "Icelandic alphabet") and ⟨[Ȣ](https://en.wikipedia.org/wiki/Ou_\(letter\) "Ou (letter)")⟩ in [Algonquian](https://en.wikipedia.org/wiki/Algonquian_languages "Algonquian languages"); borrowings from other alphabets, such as the [thorn](https://en.wikipedia.org/wiki/Thorn_\(letter\) "Thorn (letter)") ⟨þ⟩ in [Old English](https://en.wikipedia.org/wiki/Old_English_language "Old English language") and [Icelandic](https://en.wikipedia.org/wiki/Icelandic_language "Icelandic language"), which came from the [Futhark](https://en.wikipedia.org/wiki/Runic_alphabet "Runic alphabet") runes;[\[37\]](https://en.wikipedia.org/wiki/#cite_note-37) and modified existing letters, such as the [eth](https://en.wikipedia.org/wiki/Eth_\(letter\) "Eth (letter)") ⟨ð⟩ of Old English and Icelandic, which is a modified *d*. Other alphabets only use a subset of the Latin alphabet, such as Hawaiian and Italian, which uses the letters *j, k, x, y,* and *w* only in foreign words.[\[38\]](https://en.wikipedia.org/wiki/#cite_note-38)

Another notable script is [Elder Futhark](https://en.wikipedia.org/wiki/Elder_Futhark "Elder Futhark"), believed to have evolved out of one of the [Old Italic alphabets](https://en.wikipedia.org/wiki/Old_Italic_alphabet "Old Italic alphabet"). Elder Futhark gave rise to other alphabets known collectively as the [Runic alphabets](https://en.wikipedia.org/wiki/Runic_alphabet "Runic alphabet"). The Runic alphabets were used for Germanic languages from 100 CE to the late Middle Ages, being engraved on stone and jewelry, although inscriptions found on bone and wood occasionally appear. These alphabets have since been replaced with the Latin alphabet. The exception was for decorative use, where the runes remained in use until the 20th century.[\[39\]](https://en.wikipedia.org/wiki/#cite_note-39)

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/c/c4/Old_Hungarian_alphabet_of_J%C3%A1nos_Telegdi.jpg/220px-Old_Hungarian_alphabet_of_J%C3%A1nos_Telegdi.jpg)](https://en.wikipedia.org/wiki/File:Old_Hungarian_alphabet_of_J%C3%A1nos_Telegdi.jpg)

[Old Hungarian script](https://en.wikipedia.org/wiki/Old_Hungarian_script "Old Hungarian script")

The [Old Hungarian script](https://en.wikipedia.org/wiki/Old_Hungarian_script "Old Hungarian script") was the writing system of the Hungarians. It was in use during the entire history of Hungary, albeit not as an official writing system. From the 19th century, it once again became more and more popular.[\[40\]](https://en.wikipedia.org/wiki/#cite_note-40)

The [Glagolitic alphabet](https://en.wikipedia.org/wiki/Glagolitic_alphabet "Glagolitic alphabet") was the initial script of the liturgical language [Old Church Slavonic](https://en.wikipedia.org/wiki/Old_Church_Slavonic "Old Church Slavonic") and became, together with the Greek uncial script, the basis of the [Cyrillic script](https://en.wikipedia.org/wiki/Cyrillic_script "Cyrillic script"). Cyrillic is one of the most widely used modern alphabetic scripts and is notable for its use in Slavic languages and also for other languages within the former [Soviet Union](https://en.wikipedia.org/wiki/Soviet_Union "Soviet Union"). [Cyrillic alphabets](https://en.wikipedia.org/wiki/Cyrillic_alphabets "Cyrillic alphabets") include [Serbian](https://en.wikipedia.org/wiki/Serbian_Cyrillic_alphabet "Serbian Cyrillic alphabet"), [Macedonian](https://en.wikipedia.org/wiki/Macedonian_alphabet "Macedonian alphabet"), [Bulgarian](https://en.wikipedia.org/wiki/Bulgarian_alphabet "Bulgarian alphabet"), [Russian](https://en.wikipedia.org/wiki/Russian_alphabet "Russian alphabet"), [Belarusian](https://en.wikipedia.org/wiki/Belarusian_alphabet "Belarusian alphabet"), and [Ukrainian](https://en.wikipedia.org/wiki/Ukrainian_alphabet "Ukrainian alphabet"). The Glagolitic alphabet is believed to have been created by [Saints Cyril and Methodius](https://en.wikipedia.org/wiki/Saints_Cyril_and_Methodius "Saints Cyril and Methodius"), while the Cyrillic alphabet was created by [Clement of Ohrid](https://en.wikipedia.org/wiki/Clement_of_Ohrid "Clement of Ohrid"), their disciple. They feature many letters that appear to have been borrowed from or influenced by Greek and Hebrew.[\[41\]](https://en.wikipedia.org/wiki/#cite_note-41)

#### Asian alphabets

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=6 "Edit section: Asian alphabets")]

Many phonetic scripts exist in Asia. The [Arabic alphabet](https://en.wikipedia.org/wiki/Arabic_alphabet "Arabic alphabet"), [Hebrew alphabet](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet"), [Syriac alphabet](https://en.wikipedia.org/wiki/Syriac_alphabet "Syriac alphabet"), and other [abjads](https://en.wikipedia.org/wiki/Abjad "Abjad") of the Middle East are developments of the [Aramaic alphabet](https://en.wikipedia.org/wiki/Aramaic_alphabet "Aramaic alphabet").[\[42\]](https://en.wikipedia.org/wiki/#cite_note-42)[\[43\]](https://en.wikipedia.org/wiki/#cite_note-43)

Most alphabetic scripts of India and Eastern Asia descend from the [Brahmi script](https://en.wikipedia.org/wiki/Brahmi_script "Brahmi script"), believed to be a descendant of Aramaic.[\[44\]](https://en.wikipedia.org/wiki/#cite_note-44)

European alphabets, especially Latin and Cyrillic, have been adapted for many languages of Asia. Arabic is also widely used, sometimes as an abjad, as with [Urdu](https://en.wikipedia.org/wiki/Urdu_alphabet "Urdu alphabet") and [Persian](https://en.wikipedia.org/wiki/Persian_alphabet "Persian alphabet"), and sometimes as a complete alphabet, as with [Kurdish](https://en.wikipedia.org/wiki/Kurdish_alphabet "Kurdish alphabet") and [Uyghur](https://en.wikipedia.org/wiki/Uyghur_alphabet "Uyghur alphabet").[\[45\]](https://en.wikipedia.org/wiki/#cite_note-45)[\[46\]](https://en.wikipedia.org/wiki/#cite_note-FOOTNOTEZhou2003\[\[Category:Wikipedia_articles_needing_page_number_citations_from_November_2024]]%3Csup_class=%22noprint_Inline-Template_%22_style=%22white-space:nowrap;%22%3E\&#91;%3Ci%3E\[\[Wikipedia:Citing_sources|%3Cspan_title=%22This_citation_requires_a_reference_to_the_specific_page_or_range_of_pages_in_which_the_material_appears.\&#32;\(November_2024\)%22%3Epage\&nbsp;needed%3C/span%3E]]%3C/i%3E\&#93;%3C/sup%3E-46)

### Other alphabets

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=7 "Edit section: Other alphabets")]

#### Hangul

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=8 "Edit section: Hangul")]

In [Korea](https://en.wikipedia.org/wiki/Korea "Korea"), [Sejong the Great](https://en.wikipedia.org/wiki/Sejong_the_Great "Sejong the Great") created the [Hangul](https://en.wikipedia.org/wiki/Hangul "Hangul") alphabet in 1443 CE. Hangul is a unique alphabet: it is a [featural alphabet](https://en.wikipedia.org/wiki/Featural_alphabet "Featural alphabet"), where the design of many of the letters comes from a sound's place of articulation, like P looking like the widened mouth and L looking like the tongue pulled in.[\[47\]](https://en.wikipedia.org/wiki/#cite_note-47)\[*[better source needed](https://en.wikipedia.org/wiki/Wikipedia:NOTRS "Wikipedia:NOTRS")*] The creation of Hangul was planned by the government of the day,[\[48\]](https://en.wikipedia.org/wiki/#cite_note-48) and it places individual letters in syllable clusters with equal dimensions, in the same way as [Chinese characters](https://en.wikipedia.org/wiki/Chinese_characters "Chinese characters"). This change allows for mixed-script writing, where one syllable always takes up one type space no matter how many letters get stacked into building that one sound-block.[\[49\]](https://en.wikipedia.org/wiki/#cite_note-49)

#### Bopomofo

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=9 "Edit section: Bopomofo")]

[Bopomofo](https://en.wikipedia.org/wiki/Bopomofo "Bopomofo"), also referred to as *zhuyin*, is a [semi-syllabary](https://en.wikipedia.org/wiki/Semi-syllabary "Semi-syllabary") used primarily in [Taiwan](https://en.wikipedia.org/wiki/Taiwan "Taiwan") to transcribe the sounds of [Standard Chinese](https://en.wikipedia.org/wiki/Standard_Chinese "Standard Chinese"). Following the proclamation of the People's Republic of China in 1949 and its adoption of [Hanyu Pinyin](https://en.wikipedia.org/wiki/Hanyu_Pinyin "Hanyu Pinyin") in 1956, the use of bopomofo on the mainland is limited. Bopomofo developed from a form of Chinese shorthand based on Chinese characters in the early 1900s and has elements of both an alphabet and a syllabary. Like an alphabet, the phonemes of [syllable initials](https://en.wikipedia.org/wiki/Syllable_onset "Syllable onset") are represented by individual symbols, but like a syllabary, the phonemes of the [syllable finals](https://en.wikipedia.org/wiki/Syllable_rime "Syllable rime") are not; each possible final (excluding the [medial glide](https://en.wikipedia.org/wiki/Syllable_medial "Syllable medial")) has its own character, an example being *luan* written as ㄌㄨㄢ (*l-u-an*). The last symbol ㄢ takes place as the entire final *-an*. While bopomofo is not a mainstream writing system, it is still often used in ways similar to a [romanization](https://en.wikipedia.org/wiki/Romanization "Romanization") system, for aiding pronunciation and as an input method for Chinese characters on computers and cellphones.[\[50\]](https://en.wikipedia.org/wiki/#cite_note-50)\[*[better source needed](https://en.wikipedia.org/wiki/Wikipedia:NOTRS "Wikipedia:NOTRS")*]

The term "alphabet" is used by [linguists](https://en.wikipedia.org/wiki/Linguistics "Linguistics") and [paleographers](https://en.wikipedia.org/wiki/Paleographer "Paleographer") in both a wide and a narrow sense. In a broader sense, an alphabet is a *segmental* script at the [phoneme](https://en.wikipedia.org/wiki/Phoneme "Phoneme") level—that is, it has separate glyphs for individual sounds and not for larger units such as syllables or words. In the narrower sense, some scholars distinguish "true" alphabets from two other types of segmental script, [abjads](https://en.wikipedia.org/wiki/Abjad "Abjad"), and [abugidas](https://en.wikipedia.org/wiki/Abugida "Abugida"). These three differ in how they treat vowels. Abjads have letters for consonants and leave most vowels unexpressed. Abugidas are also consonant-based but indicate vowels with [diacritics](https://en.wikipedia.org/wiki/Diacritic "Diacritic"), a systematic graphic modification of the consonants.[\[51\]](https://en.wikipedia.org/wiki/#cite_note-51) The earliest known alphabet using this sense is the [Wadi el-Hol script](https://en.wikipedia.org/wiki/Middle_Bronze_Age_alphabets "Middle Bronze Age alphabets"), believed to be an abjad. Its successor, [Phoenician](https://en.wikipedia.org/wiki/Phoenician_alphabet "Phoenician alphabet"), is the ancestor of modern alphabets, including [Arabic](https://en.wikipedia.org/wiki/Arabic_alphabet "Arabic alphabet"), [Greek](https://en.wikipedia.org/wiki/Greek_alphabet "Greek alphabet"), [Latin](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet") (via the [Old Italic alphabet](https://en.wikipedia.org/wiki/Old_Italic_alphabet "Old Italic alphabet")), [Cyrillic](https://en.wikipedia.org/wiki/Cyrillic "Cyrillic") (via the Greek alphabet), and [Hebrew](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet") (via [Aramaic](https://en.wikipedia.org/wiki/Aramaic_alphabet "Aramaic alphabet")).[\[52\]](https://en.wikipedia.org/wiki/#cite_note-52)[\[53\]](https://en.wikipedia.org/wiki/#cite_note-53)

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e4/Venn_diagram_gr_la_ru.svg/263px-Venn_diagram_gr_la_ru.svg.png)](https://en.wikipedia.org/wiki/File:Venn_diagram_gr_la_ru.svg)

A [Venn diagram](https://en.wikipedia.org/wiki/Venn_diagram "Venn diagram") showing the [Greek](https://en.wikipedia.org/wiki/Greek_alphabet "Greek alphabet") (left), [Cyrillic](https://en.wikipedia.org/wiki/Cyrillic_script "Cyrillic script") (bottom) and [Latin](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet") (right) alphabets, which share many of the same [letters](https://en.wikipedia.org/wiki/Letter_\(alphabet\) "Letter (alphabet)"), although they have different pronunciations

Examples of present-day abjads are the [Arabic](https://en.wikipedia.org/wiki/Arabic_script "Arabic script") and [Hebrew scripts](https://en.wikipedia.org/wiki/Hebrew_script "Hebrew script");[\[54\]](https://en.wikipedia.org/wiki/#cite_note-54) true alphabets include [Latin](https://en.wikipedia.org/wiki/Latin_script "Latin script"), Cyrillic, and Korean hangul; and abugidas, used to write [Tigrinya](https://en.wikipedia.org/wiki/Tigrinya_language "Tigrinya language"), [Amharic](https://en.wikipedia.org/wiki/Amharic_language "Amharic language"), [Hindi](https://en.wikipedia.org/wiki/Hindi "Hindi"), and [Thai](https://en.wikipedia.org/wiki/Thai_language "Thai language"). The [Canadian Aboriginal syllabics](https://en.wikipedia.org/wiki/Canadian_Aboriginal_syllabics "Canadian Aboriginal syllabics") are also an abugida, rather than a syllabary, as their name would imply, because each glyph stands for a consonant and is modified by rotation to represent the following vowel. In a true syllabary, each consonant-vowel combination gets represented by a separate glyph.[\[55\]](https://en.wikipedia.org/wiki/#cite_note-55)

All three types may be augmented with syllabic glyphs. [Ugaritic](https://en.wikipedia.org/wiki/Ugaritic_script "Ugaritic script"), for example, is essentially an abjad but has syllabic letters for /ʔa, ʔi, ʔu/[\[56\]](https://en.wikipedia.org/wiki/#cite_note-56)[\[57\]](https://en.wikipedia.org/wiki/#cite_note-57) These are the only times that vowels are indicated. [Coptic](https://en.wikipedia.org/wiki/Coptic_alphabet "Coptic alphabet") has a letter for /ti/.[\[58\]](https://en.wikipedia.org/wiki/#cite_note-58)\[*[better source needed](https://en.wikipedia.org/wiki/Wikipedia:NOTRS "Wikipedia:NOTRS")*] [Devanagari](https://en.wikipedia.org/wiki/Devanagari "Devanagari") is typically an abugida augmented with dedicated letters for initial vowels, though some traditions use अ as a [zero consonant](https://en.wikipedia.org/wiki/Zero_consonant "Zero consonant") as the graphic base for such vowels.[\[59\]](https://en.wikipedia.org/wiki/#cite_note-Indo-Aryan-59)[\[60\]](https://en.wikipedia.org/wiki/#cite_note-60)

The boundaries between the three types of segmental scripts are not always clear-cut. For example, [Sorani](https://en.wikipedia.org/wiki/Sorani "Sorani") Kurdish is written in the [Arabic script](https://en.wikipedia.org/wiki/Arabic_script "Arabic script"), which, when used for other languages, is an abjad. In [Kurdish](https://en.wikipedia.org/wiki/Kurdish_languages "Kurdish languages"), writing the vowels is mandatory, and whole letters are used, so the script is a true alphabet. Other languages may use a Semitic abjad with forced vowel diacritics, effectively making them abugidas. On the other hand, the [ʼPhags-pa script](https://en.wikipedia.org/wiki/%CA%BCPhags-pa_script "ʼPhags-pa script") of the [Mongol Empire](https://en.wikipedia.org/wiki/Mongol_Empire "Mongol Empire") was based closely on the [Tibetan abugida](https://en.wikipedia.org/wiki/Tibetan_script "Tibetan script"), but vowel marks are written after the preceding consonant rather than as diacritic marks. Although short *a* is not written, as in the Indic abugidas, The source of the term "abugida", namely the [Ge'ez abugida](https://en.wikipedia.org/wiki/Ge%27ez_abugida "Ge'ez abugida") now used for [Amharic](https://en.wikipedia.org/wiki/Amharic_language "Amharic language") and [Tigrinya](https://en.wikipedia.org/wiki/Tigrinya_language "Tigrinya language"), has assimilated into their consonant modifications. It is no longer systematic and must be learned as a syllabary rather than as a segmental script. Even more extreme, the Pahlavi abjad eventually became [logographic](https://en.wikipedia.org/wiki/Logogram "Logogram").[\[61\]](https://en.wikipedia.org/wiki/#cite_note-61)

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/e/e2/Ethiopic_genesis_%28ch._29%2C_v._11-16%29%2C_15th_century_%28The_S.S._Teacher%27s_Edition-The_Holy_Bible_-_Plate_XII%2C_1%29.jpg/220px-Ethiopic_genesis_%28ch._29%2C_v._11-16%29%2C_15th_century_%28The_S.S._Teacher%27s_Edition-The_Holy_Bible_-_Plate_XII%2C_1%29.jpg)](https://en.wikipedia.org/wiki/File:Ethiopic_genesis_\(ch._29,_v._11-16\),_15th_century_\(The_S.S._Teacher%27s_Edition-The_Holy_Bible_-_Plate_XII,_1\).jpg)

[Ge'ez Script](https://en.wikipedia.org/wiki/Ge%27ez_Script "Ge'ez Script") of [Ethiopia](https://en.wikipedia.org/wiki/Ethiopia "Ethiopia") and [Eritrea](https://en.wikipedia.org/wiki/Eritrea "Eritrea")

Thus the primary [categorisation](https://en.wikipedia.org/wiki/Categorisation "Categorisation") of alphabets reflects how they treat vowels. For [tonal languages](https://en.wikipedia.org/wiki/Tone_\(linguistics\) "Tone (linguistics)"), further classification can be based on their treatment of tone. Though names do not yet exist to distinguish the various types. Some alphabets disregard tone entirely, especially when it does not carry a heavy functional load,[\[62\]](https://en.wikipedia.org/wiki/#cite_note-62) as in [Somali](https://en.wikipedia.org/wiki/Somali_language "Somali language") and many other languages of Africa and the Americas.[\[63\]](https://en.wikipedia.org/wiki/#cite_note-63) Most commonly, tones are indicated by diacritics, which is how vowels are treated in abugidas, which is the case for [Vietnamese](https://en.wikipedia.org/wiki/Vietnamese_alphabet "Vietnamese alphabet") (a true alphabet) and [Thai](https://en.wikipedia.org/wiki/Thai_script "Thai script") (an abugida). In Thai, the tone is determined primarily by a consonant, with diacritics for disambiguation. In the [Pollard script](https://en.wikipedia.org/wiki/Pollard_script "Pollard script"), an abugida, vowels are indicated by diacritics. The placing of the diacritic relative to the consonant is modified to indicate the tone.[\[46\]](https://en.wikipedia.org/wiki/#cite_note-FOOTNOTEZhou2003\[\[Category:Wikipedia_articles_needing_page_number_citations_from_November_2024]]%3Csup_class=%22noprint_Inline-Template_%22_style=%22white-space:nowrap;%22%3E\&#91;%3Ci%3E\[\[Wikipedia:Citing_sources|%3Cspan_title=%22This_citation_requires_a_reference_to_the_specific_page_or_range_of_pages_in_which_the_material_appears.\&#32;\(November_2024\)%22%3Epage\&nbsp;needed%3C/span%3E]]%3C/i%3E\&#93;%3C/sup%3E-46) More rarely, a script may have separate letters for tones, as is the case for [Hmong](https://en.wikipedia.org/wiki/Hmong_alphabet "Hmong alphabet") and [Zhuang](https://en.wikipedia.org/wiki/Zhuang_alphabet "Zhuang alphabet").[\[64\]](https://en.wikipedia.org/wiki/#cite_note-64) For many, regardless of whether letters or diacritics get used, the most common tone is not marked, just as the most common vowel is not marked in Indic abugidas. In [Zhuyin](https://en.wikipedia.org/wiki/Zhuyin "Zhuyin"), not only is one of the tones unmarked; but there is a diacritic to indicate a lack of tone, like the [virama](https://en.wikipedia.org/wiki/Virama "Virama") of Indic.\[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed "Wikipedia:Citation needed")*]

## Alphabetical order

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=11 "Edit section: Alphabetical order")]

Main article: [Alphabetical order](https://en.wikipedia.org/wiki/Alphabetical_order "Alphabetical order")

Alphabets often come to be associated with a standard ordering of their letters; this is for [collation](https://en.wikipedia.org/wiki/Collation "Collation")—namely, for listing words and other items in *[alphabetical order](https://en.wikipedia.org/wiki/Alphabetical_order "Alphabetical order")*.[\[65\]](https://en.wikipedia.org/wiki/#cite_note-65)

### Latin alphabets

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=12 "Edit section: Latin alphabets")]

The ordering of the [Latin alphabet](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet") ([A](https://en.wikipedia.org/wiki/A "A") [B](https://en.wikipedia.org/wiki/B "B") [C](https://en.wikipedia.org/wiki/C "C") [D](https://en.wikipedia.org/wiki/D "D") [E](https://en.wikipedia.org/wiki/E "E") [F](https://en.wikipedia.org/wiki/F "F") [G](https://en.wikipedia.org/wiki/G "G") [H](https://en.wikipedia.org/wiki/H "H") [I](https://en.wikipedia.org/wiki/I "I") [J](https://en.wikipedia.org/wiki/J "J") [K](https://en.wikipedia.org/wiki/K "K") [L](https://en.wikipedia.org/wiki/L "L") [M](https://en.wikipedia.org/wiki/M "M") [N](https://en.wikipedia.org/wiki/N "N") [O](https://en.wikipedia.org/wiki/O "O") [P](https://en.wikipedia.org/wiki/P "P") [Q](https://en.wikipedia.org/wiki/Q "Q") [R](https://en.wikipedia.org/wiki/R "R") [S](https://en.wikipedia.org/wiki/S "S") [T](https://en.wikipedia.org/wiki/T "T") [U](https://en.wikipedia.org/wiki/U "U") [V](https://en.wikipedia.org/wiki/V "V") [W](https://en.wikipedia.org/wiki/W "W") [X](https://en.wikipedia.org/wiki/X "X") [Y](https://en.wikipedia.org/wiki/Y "Y") [Z](https://en.wikipedia.org/wiki/Z "Z")), which derives from the Northwest Semitic "Abgad" order,[\[66\]](https://en.wikipedia.org/wiki/#cite_note-66) is already well established. Although, languages using this alphabet have different conventions for their treatment of modified letters (such as the French *é*, *à*, and *ô*) and certain combinations of letters ([multigraphs](https://en.wikipedia.org/wiki/Multigraph_\(orthography\) "Multigraph (orthography)")). In French, these are not considered to be additional letters for collation. However, in [Icelandic](https://en.wikipedia.org/wiki/Icelandic_language "Icelandic language"), the accented letters such as *á*, *í*, and *ö* are considered distinct letters representing different vowel sounds from sounds represented by their unaccented counterparts. In Spanish, *ñ* is considered a separate letter, but accented vowels such as *á* and *é* are not. The *ll* and *ch* were also formerly considered single letters and sorted separately after *l* and *c*, but in 1994, the tenth congress of the [Association of Spanish Language Academies](https://en.wikipedia.org/wiki/Association_of_Spanish_Language_Academies "Association of Spanish Language Academies") changed the collating order so that *ll* came to be sorted between *lk* and *lm* in the dictionary and *ch* came to be sorted between *cg* and *ci*; those digraphs were still formally designated as letters, but in 2010 the *[Real Academia Española](https://en.wikipedia.org/wiki/Real_Academia_Espa%C3%B1ola "Real Academia Española")* changed it, so they are no longer considered letters at all.[\[67\]](https://en.wikipedia.org/wiki/#cite_note-67)[\[68\]](https://en.wikipedia.org/wiki/#cite_note-68)

In German, words starting with *sch-* (which spells the German phoneme /[ʃ](https://en.wikipedia.org/wiki/Voiceless_postalveolar_fricative "Voiceless postalveolar fricative")/) are inserted between words with initial *sca-* and *sci-* (all incidentally loanwords) instead of appearing after the initial *sz*, as though it were a single letter, which contrasts several languages such as [Albanian](https://en.wikipedia.org/wiki/Albanian_alphabet "Albanian alphabet"), in which *dh-*, *ë-*, *gj-*, *ll-*, *rr-*, *th-*, *xh-,* and *zh-,* which all represent phonemes and considered separate single letters, would follow the letters ⟨d, e, g, l, n, r, t, x, z⟩ respectively, as well as Hungarian and Welsh. Further, German words with an [umlaut](https://en.wikipedia.org/wiki/Umlaut_\(diacritic\) "Umlaut (diacritic)") get collated ignoring the umlaut as—contrary to [Turkish](https://en.wikipedia.org/wiki/Turkish_alphabet "Turkish alphabet"), which adopted the [graphemes](https://en.wikipedia.org/wiki/Grapheme "Grapheme") **ö** and **ü**, and where a word like *tüfek* would come after *tuz*, in the dictionary. An exception is the German telephone directory, where umlauts are sorted like *ä*=*ae* since names such as *Jäger* also appear with the spelling *Jaeger* and are not distinguished in the spoken language.[\[69\]](https://en.wikipedia.org/wiki/#cite_note-69)

The [Danish](https://en.wikipedia.org/wiki/Danish_orthography "Danish orthography") and [Norwegian](https://en.wikipedia.org/wiki/Norwegian_orthography "Norwegian orthography") alphabets end with ⟨æ, ø, å⟩,[\[70\]](https://en.wikipedia.org/wiki/#cite_note-70)[\[71\]](https://en.wikipedia.org/wiki/#cite_note-71) whereas the Swedish conventionally put ⟨å, ä, ö⟩ at the end. However, æ phonetically corresponds with ⟨ä⟩, as does ⟨ø⟩ and ⟨ö⟩.[\[72\]](https://en.wikipedia.org/wiki/#cite_note-72)

### Early alphabets

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=13 "Edit section: Early alphabets")]

It is unknown whether the earliest alphabets had a defined sequence. Some alphabets today, such as the [Hanuno'o script](https://en.wikipedia.org/wiki/Hanuno%27o_script "Hanuno'o script"), are learned one letter at a time, in no particular order, and are not used for [collation](https://en.wikipedia.org/wiki/Collation "Collation") where a definite order is required.[\[73\]](https://en.wikipedia.org/wiki/#cite_note-73) However, a dozen [Ugaritic](https://en.wikipedia.org/wiki/Ugaritic_alphabet "Ugaritic alphabet") tablets from the fourteenth century BCE preserve the alphabet in two sequences. One, the *ABCDE* order later used in Phoenician, has continued with minor changes in [Hebrew](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet"), [Greek](https://en.wikipedia.org/wiki/Greek_alphabet "Greek alphabet"), [Armenian](https://en.wikipedia.org/wiki/Armenian_alphabet "Armenian alphabet"), [Gothic](https://en.wikipedia.org/wiki/Gothic_alphabet "Gothic alphabet"), [Cyrillic](https://en.wikipedia.org/wiki/Cyrillic "Cyrillic"), and [Latin](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet"); the other, *HMĦLQ,* was used in southern Arabia and is preserved today in [Geʻez](https://en.wikipedia.org/w/index.php?title=Ge%CA%BBez_alphabet\&action=edit\&redlink=1 "Geʻez alphabet (page does not exist)").[\[74\]](https://en.wikipedia.org/wiki/#cite_note-74) Both orders have therefore been stable for at least 3000 years.[\[75\]](https://en.wikipedia.org/wiki/#cite_note-75)\[*[better source needed](https://en.wikipedia.org/wiki/Wikipedia:NOTRS "Wikipedia:NOTRS")*]

[Runic](https://en.wikipedia.org/wiki/Runic_alphabet "Runic alphabet") used an unrelated [Futhark](https://en.wikipedia.org/wiki/Elder_Futhark "Elder Futhark") sequence, which got [simplified](https://en.wikipedia.org/wiki/Younger_Futhark "Younger Futhark") later on.[\[76\]](https://en.wikipedia.org/wiki/#cite_note-76) [Arabic](https://en.wikipedia.org/wiki/Arabic_alphabet "Arabic alphabet") usually uses its sequence, although Arabic retains the traditional [abjadi order](https://en.wikipedia.org/wiki/Abjadi_order "Abjadi order"), which is used for numbers.\[*[citation needed](https://en.wikipedia.org/wiki/Wikipedia:Citation_needed "Wikipedia:Citation needed")*]

The [Brahmic family](https://en.wikipedia.org/wiki/Brahmic_family "Brahmic family") of alphabets used in India uses a unique order based on [phonology](https://en.wikipedia.org/wiki/Phonology "Phonology"): The letters are arranged according to how and where the sounds get produced in the mouth. This organization is present in Southeast Asia, Tibet, Korean [hangul](https://en.wikipedia.org/wiki/Hangul "Hangul"), and even Japanese [kana](https://en.wikipedia.org/wiki/Kana "Kana"), which is not an alphabet.[\[77\]](https://en.wikipedia.org/wiki/#cite_note-77)

## Acrophony

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=14 "Edit section: Acrophony")]

In Phoenician, each letter got associated with a word that begins with that sound. This is called [acrophony](https://en.wikipedia.org/wiki/Acrophony "Acrophony") and is continuously used to varying degrees in [Samaritan](https://en.wikipedia.org/wiki/Samaritan_alphabet "Samaritan alphabet"), [Aramaic](https://en.wikipedia.org/wiki/Aramaic_alphabet "Aramaic alphabet"), [Syriac](https://en.wikipedia.org/wiki/Syriac_alphabet "Syriac alphabet"), [Hebrew](https://en.wikipedia.org/wiki/Hebrew_alphabet "Hebrew alphabet"), [Greek](https://en.wikipedia.org/wiki/Greek_alphabet "Greek alphabet"), and [Arabic](https://en.wikipedia.org/wiki/Arabic_alphabet "Arabic alphabet").[\[78\]](https://en.wikipedia.org/wiki/#cite_note-78)[\[79\]](https://en.wikipedia.org/wiki/#cite_note-79)\[*[better source needed](https://en.wikipedia.org/wiki/Wikipedia:NOTRS "Wikipedia:NOTRS")*]

Acrophony was abandoned in [Latin](https://en.wikipedia.org/wiki/Latin_alphabet "Latin alphabet"). It referred to the letters by adding a vowel—usually ⟨e⟩, sometimes ⟨a⟩ or ⟨u⟩—before or after the consonant. Two exceptions were [Y](https://en.wikipedia.org/wiki/Y "Y") and [Z](https://en.wikipedia.org/wiki/Z "Z"), which were borrowed from the Greek alphabet rather than Etruscan. They were known as *Y Graeca* "Greek Y" and *zeta* (from Greek)—this discrepancy was inherited by many European languages, as in the term *zed* for Z in all forms of English, other than American English.[\[80\]](https://en.wikipedia.org/wiki/#cite_note-80) Over time names sometimes shifted or were added, as in *double U* for [W](https://en.wikipedia.org/wiki/W "W"), or "double V" in French, the English name for Y, and the American *zee* for Z. Comparing them in English and French gives a clear reflection of the [Great Vowel Shift](https://en.wikipedia.org/wiki/Great_Vowel_Shift "Great Vowel Shift"): A, B, C, and D are pronounced /eɪ, biː, siː, diː/ in today's English, but in contemporary French they are /a, be, se, de/.[\[81\]](https://en.wikipedia.org/wiki/#cite_note-81) The French names (from which the English names got derived) preserve the qualities of the English vowels before the Great Vowel Shift. By contrast, the names of F, L, M, N, and S (/ɛf, ɛl, ɛm, ɛn, ɛs/) remain the same in both languages because "short" vowels were largely unaffected by the Shift.[\[82\]](https://en.wikipedia.org/wiki/#cite_note-82)

In Cyrillic, originally, acrophony was present using Slavic words. The first three words going, azŭ, buky, vědě, with the Cyrillic collation order being, А, Б, В. However, this was later abandoned in favor of a system similar to Latin.[\[83\]](https://en.wikipedia.org/wiki/#cite_note-83)

## Orthography and pronunciation

\[[edit](https://en.wikipedia.org/w/index.php?title=Alphabet\&action=edit\&section=15 "Edit section: Orthography and pronunciation")]

Main article: [Phonemic orthography](https://en.wikipedia.org/wiki/Phonemic_orthography "Phonemic orthography")

When an alphabet is adopted or developed to represent a given language, an [orthography](https://en.wikipedia.org/wiki/Orthography "Orthography") generally comes into being, providing rules for [spelling](https://en.wikipedia.org/wiki/Spelling "Spelling") words, following the principle on which alphabets get based. These rules will map letters of the alphabet to the [phonemes](https://en.wikipedia.org/wiki/Phoneme "Phoneme") of the spoken language.[\[84\]](https://en.wikipedia.org/wiki/#cite_note-84) In a perfectly [phonemic orthography](https://en.wikipedia.org/wiki/Phonemic_orthography "Phonemic orthography"), there would be a consistent one-to-one correspondence between the letters and the phonemes so that a writer could predict the spelling of a word given its pronunciation, and a speaker would always know the pronunciation of a word given its spelling, and vice versa. However, this ideal is usually never achieved in practice. Languages can come close to it, such as Spanish and [Finnish](https://en.wikipedia.org/wiki/Finnish_language "Finnish language"). Others, such as English, deviate from it to a much larger degree.[\[85\]](https://en.wikipedia.org/wiki/#cite_note-85)

The pronunciation of a language often evolves independently of its writing system. Writing systems have been borrowed for languages the orthography was not initially made to use. The degree to which letters of an alphabet correspond to phonemes of a language varies.[\[86\]](https://en.wikipedia.org/wiki/#cite_note-86)

Languages may fail to achieve a one-to-one correspondence between letters and sounds in any of several ways:

- A language may represent a given phoneme by combinations of letters rather than just a single letter. Two-letter combinations are called [digraphs](https://en.wikipedia.org/wiki/Digraph_\(orthography\) "Digraph (orthography)"), and three-letter groups are called [trigraphs](https://en.wikipedia.org/wiki/Trigraph_\(orthography\) "Trigraph (orthography)"). German uses the [tetragraphs](https://en.wikipedia.org/wiki/Tetragraph "Tetragraph") (four letters) "tsch" for the phoneme German pronunciation: [\[tʃ\]](https://en.wikipedia.org/wiki/Help:IPA/Standard_German "Help:IPA/Standard German") and (in a few borrowed words) "dsch" for \[dʒ].[\[87\]](https://en.wikipedia.org/wiki/#cite_note-87) [Kabardian](https://en.wikipedia.org/wiki/Kabardian_language "Kabardian language") also uses a tetragraph for one of its phonemes, namely "кхъу."[\[88\]](https://en.wikipedia.org/wiki/#cite_note-88) Two letters representing one sound occur in several instances in Hungarian as well (where, for instance, *cs* stands for \[tʃ], *sz* for \[s], *zs* for \[ʒ], *dzs* for \[dʒ]).[\[89\]](https://en.wikipedia.org/wiki/#cite_note-89)
- A language may represent the same phoneme with two or more different letters or combinations of letters. An example is [modern Greek](https://en.wikipedia.org/wiki/Modern_Greek "Modern Greek") which may write the phoneme Greek pronunciation: [\[i\]](https://en.wikipedia.org/wiki/Help:IPA/Greek "Help:IPA/Greek") in six different ways: ⟨ι⟩, ⟨η⟩, ⟨υ⟩, ⟨ει⟩, ⟨οι⟩, and ⟨υι⟩.[\[90\]](https://en.wikipedia.org/wiki/#cite_note-90)
- A language may spell some words with unpronounced letters that exist for historical or other reasons. For example, the spelling of the Thai word for 'beer' เบียร์ retains a letter for the final consonant /r/ present in the English word it borrows, but silences it.[\[91\]](https://en.wikipedia.org/wiki/#cite_note-91)
- Pronunciation of individual words may change according to the presence of surrounding words in a sentence, for example, in [sandhi](https://en.wikipedia.org/wiki/Sandhi "Sandhi").[\[92\]](https://en.wikipedia.org/wiki/#cite_note-92)
- Different dialects of a language may use different phonemes for the same word.[\[93\]](https://en.wikipedia.org/wiki/#cite_note-93)\[*[better source needed](https://en.wikipedia.org/wiki/Wikipedia:NOTRS "Wikipedia:NOTRS")*]
- A language may use different sets of symbols or rules for distinct vocabulary items, typically for foreign words, such as in the Japanese [katakana](https://en.wikipedia.org/wiki/Katakana "Katakana") syllabary is used for foreign words, and there are rules in English for using loanwords from other languages.[\[94\]](https://en.wikipedia.org/wiki/#cite_note-94)[\[95\]](https://en.wikipedia.org/wiki/#cite_note-95)

National languages sometimes elect to address the problem of dialects by associating the alphabet with the national standard. Some national languages like [Finnish](https://en.wikipedia.org/wiki/Finnish_language "Finnish language"), [Armenian](https://en.wikipedia.org/wiki/Armenian_language "Armenian language"), [Turkish](https://en.wikipedia.org/wiki/Turkish_language "Turkish language"), Russian, [Serbo-Croatian](https://en.wikipedia.org/wiki/Serbo-Croatian_language "Serbo-Croatian language") ([Serbian](https://en.wikipedia.org/wiki/Serbian_language "Serbian language"), [Croatian](https://en.wikipedia.org/wiki/Croatian_language "Croatian language"), and [Bosnian](https://en.wikipedia.org/wiki/Bosnian_language "Bosnian language")), and [Bulgarian](https://en.wikipedia.org/wiki/Bulgarian_language "Bulgarian language") have a very regular spelling system with nearly one-to-one correspondence between letters and phonemes.[\[96\]](https://en.wikipedia.org/wiki/#cite_note-96) Similarly, the Italian verb corresponding to 'spell (out),' *compitare*, is unknown to many Italians because spelling is usually trivial, as Italian spelling is highly phonemic.[\[97\]](https://en.wikipedia.org/wiki/#cite_note-97) In standard Spanish, one can tell the pronunciation of a word from its spelling, but not vice versa, as phonemes sometimes can be represented in more than one way, but a given letter is consistently pronounced. French using [silent letters](https://en.wikipedia.org/wiki/Silent_letter "Silent letter"), [nasal vowels](https://en.wikipedia.org/wiki/Nasal_vowel "Nasal vowel"), and [elision](https://en.wikipedia.org/wiki/Elision "Elision"), may seem to lack much correspondence between the spelling and pronunciation. However, its rules on pronunciation, though complex, are consistent and predictable with a fair degree of accuracy.[\[98\]](https://en.wikipedia.org/wiki/#cite_note-98)

At the other extreme are languages such as English, where pronunciations mostly have to be memorized as they do not correspond to the spelling consistently. For English, this is because the [Great Vowel Shift](https://en.wikipedia.org/wiki/Great_Vowel_Shift "Great Vowel Shift") occurred after the orthography got established and because English has acquired a large number of loanwords at different times, retaining their original spelling at varying levels.[\[99\]](https://en.wikipedia.org/wiki/#cite_note-99) However, even English has general, albeit complex, rules that predict pronunciation from spelling. Rules like this are usually successful. However, rules to predict spelling from pronunciation have a higher failure rate.[\[100\]](https://en.wikipedia.org/wiki/#cite_note-100)

Sometimes, countries have the written language undergo a [spelling reform](https://en.wikipedia.org/wiki/Spelling_reform "Spelling reform") to realign the writing with the contemporary spoken language. These can range from simple spelling changes and word forms to switching the entire writing system. For example, Turkey switched from the Arabic alphabet to a Latin-based [Turkish alphabet](https://en.wikipedia.org/wiki/Turkish_alphabet "Turkish alphabet"),[\[101\]](https://en.wikipedia.org/wiki/#cite_note-101) and [Kazakh](https://en.wikipedia.org/wiki/Kazakh_alphabets "Kazakh alphabets") changed from an Arabic script to a Cyrillic script due to the Soviet Union's influence. In 2021, it made a transition to the Latin alphabet, similar to Turkish.[\[102\]](https://en.wikipedia.org/wiki/#cite_note-102)[\[103\]](https://en.wikipedia.org/wiki/#cite_note-103) The Cyrillic script used to be official in Uzbekistan and Turkmenistan before they switched to the Latin alphabet. Uzbekistan is reforming the alphabet to use diacritics on the letters that are marked by apostrophes and the letters that are digraphs.[\[104\]](https://en.wikipedia.org/wiki/#cite_note-104)[\[105\]](https://en.wikipedia.org/wiki/#cite_note-105)

The standard system of symbols used by [linguists](https://en.wikipedia.org/wiki/Linguist "Linguist") to represent sounds in any language, independently of orthography, is called the [International Phonetic Alphabet](https://en.wikipedia.org/wiki/International_Phonetic_Alphabet "International Phonetic Alphabet").[\[106\]](https://en.wikipedia.org/wiki/#cite_note-106)
