# ブラックミュージック

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/8/80/Henry_Ossawa_Tanner%2C_The_Banjo_Lesson_%28darker%29.jpg/220px-Henry_Ossawa_Tanner%2C_The_Banjo_Lesson_%28darker%29.jpg)](https://ja.wikipedia.org/wiki/File:Henry_Ossawa_Tanner,_The_Banjo_Lesson_\(darker\).jpg)

アフリカ系アメリカ人画家[ヘンリー・オサワ・タナー](https://ja.wikipedia.org/wiki/%E3%83%98%E3%83%B3%E3%83%AA%E3%83%BC%E3%83%BB%E3%82%AA%E3%82%B5%E3%83%AF%E3%83%BB%E3%82%BF%E3%83%8A%E3%83%BC?action=edit\&redlink=1 "ヘンリー・オサワ・タナー")による、[バンジョー](https://ja.wikipedia.org/wiki/%E3%83%90%E3%83%B3%E3%82%B8%E3%83%A7%E3%83%BC?action=edit\&redlink=1 "バンジョー")を練習する黒人を描いた『[Template:仮リンク](https://ja.wikipedia.org/wiki/Template:%E4%BB%AE%E3%83%AA%E3%83%B3%E3%82%AF?action=edit\&redlink=1 "Template:仮リンク")』（1893年）

**ブラックミュージック** (**Transclusion error: {{[En](https://ja.wikipedia.org/wiki/Template:En "Template:En")}} is only for use in File namespace. Use {{[langx](https://ja.wikipedia.org/wiki/Template:Langx "Template:Langx")|en}} or {{[in lang](https://ja.wikipedia.org/wiki/Template:In_lang "Template:In lang")|en}} instead.**) あるいは**黒人音楽**（こくじんおんがく）とは、[アメリカ合衆国](https://ja.wikipedia.org/wiki/%E3%82%A2%E3%83%A1%E3%83%AA%E3%82%AB%E5%90%88%E8%A1%86%E5%9B%BD?action=edit\&redlink=1 "アメリカ合衆国")をはじめとする[アメリカ](https://ja.wikipedia.org/wiki/%E3%82%A2%E3%83%A1%E3%83%AA%E3%82%AB%E5%B7%9E?action=edit\&redlink=1 "アメリカ州")地域における[黒人](https://ja.wikipedia.org/wiki/%E3%82%A2%E3%83%95%E3%83%AA%E3%82%AB%E7%B3%BB%E3%82%A2%E3%83%A1%E3%83%AA%E3%82%AB%E4%BA%BA?action=edit\&redlink=1 "アフリカ系アメリカ人")発祥の[音楽](https://ja.wikipedia.org/wiki/%E9%9F%B3%E6%A5%BD?action=edit\&redlink=1 "音楽")の総称を表す言葉。
